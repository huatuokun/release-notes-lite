# Contributing

Thanks for taking a look at `release-notes-lite`.

## Quick start

1. Fork the repository.
2. Create a branch.
3. Run the tests with `python -m unittest discover -s tests -t .`.
4. Open a pull request with a focused description.

## Good contributions

- Better commit grouping
- Smarter git range detection
- More output formats
- Documentation improvements
- Regression tests

Please keep changes small and include tests when behavior changes.
